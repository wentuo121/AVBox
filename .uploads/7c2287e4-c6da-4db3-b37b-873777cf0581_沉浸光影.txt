// 沉浸光影：动态取色沉浸主视觉。同时开启 TMDB 集成和自动刮削后，轮播换成 TMDB 无字横图、标题 logo 和宣传语，横屏附带简介；没开时用站源的图文。
//
// 想写同款？这些能力对所有主题开放：
//   data.home.tmdb.enabled      TMDB 集成 + 自动刮削都开着（且配了 Token）时为 true，另有 integration / autoScrape / configured 单项
//   推荐项 item.tmdb            这一项的 TMDB 素材已到齐
//   item.titleLogo / backdrop / tmdbPoster   标题 logo、无字横图、竖版海报，地址已拼好，直接给 T4Image
//   item.tagline / overview / subtitle / tmdbYear / tmdbType / genres / rating / runtime   宣传语、简介、副标题、年份、电影或剧集、类型、评分、时长或集数
//   data.home.immersive.primaryColor / secondaryColor / backgroundColor / accentColor   从当前主视觉取的四个颜色
//   T4Image(fadeBottom: 0.4, fadeLeft: 0.5, fadeLeftMin: 0.2, drift: true)   大图边缘渐隐成透明、缓慢推拉
//   PeekCarousel(style: "bleed", indicatorInset: 36.0, indicatorBottom: 30.0)   通栏转场、指示器位置
// 主题里写到 TMDB 字段，壳子才会去查 TMDB，并把沉浸取色的主视觉换成 TMDB 横图；编辑器「片段」里有现成写法。
